# Gerenciador de Tarefas Acadêmicas

Gerenciador de tarefas acadêmicas desenvolvido durante a disciplina de Desenvolvimento Frontend.

## E4

Nesta etapa foram implementados:

- Estado único da aplicação;
- Busca por título;
- Filtro por status;
- Filtro por prioridade;
- Ordenação por prazo;
- Limpeza dos filtros;
- Combinação de busca e filtros;
- Estados de carregamento, erro, origem vazia e resultado vazio;
- Atualização acessível dos resultados;
- Publicação no GitHub Pages.
